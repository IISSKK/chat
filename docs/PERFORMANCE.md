# Скорость на телефоне

Замер Lighthouse (мобильный профиль: медленный 4G, процессор в 4 раза слабее), боевая сборка:

| Страница | Скорость | Доступность | SEO | LCP |
| --- | --- | --- | --- | --- |
| Главная | 92 | 100 | 100 | 1,4 с |
| Каталог | 99 | 100 | 100 | 1,2 с |
| Объявление | 96 | 100 | 100 | 1,1 с |
| Запчасти / О нас | 98 / 96 | 100 | 100 | 1,1 с |

## Что сделано
- Основной текст набран системным шрифтом телефона (не грузится по сети); по сети только Manrope для заголовков (38 КБ вместо 187 КБ).
- Нет предзагрузки ссылок: открытие главной даёт 29 запросов вместо 57, сервер не рендерит 25 страниц «на всякий случай».
- Кнопки WhatsApp на карточках без JavaScript (нативный `<details>`), меньше «живых» блоков для гидрации.
- Первые карточки и первый экран появляются сразу, без ожидания скриптов; остальное — по прокрутке.
- Картинки: `srcset` (640 px для телефона, 1600 px для компьютера), первая картинка с приоритетом, остальные лениво.
- На телефоне в подборках главной по 4 карточки вместо 6; словарь для браузера урезан до нужных разделов.
- Страницы разрешено кешировать браузером для кнопки «Назад» (нет `no-store`); админка по-прежнему не кешируется.
- Кнопки не меньше 40–44 px, поля ввода 16 px (iOS не приближает страницу), `inert` для скрытого меню.

## Как перемерить
```bash
npx lighthouse https://ваш-домен --only-categories=performance,accessibility,seo --form-factor=mobile --view
```
Или откройте адрес на pagespeed.web.dev. Мерять нужно на боевом домене, а не на `localhost`.
