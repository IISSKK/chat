# Как работать с сервером

Сайт живёт на VPS. Терминал сервера — это SSH: `ssh user@IP-сервера` (вход по ключу, не по паролю).

**Обычный порядок работы**
1. Задача пишется в админке («Задачи по сайту») или напрямую разработчику.
2. Правки делаются в репозитории (ветка на GitHub), проверяются локально: `npm run dev`.
3. На сервере: `cd ~/chat && ./deploy/update.sh` — скрипт сам сделает копию базы, обновит код, соберёт и перезапустит сайт.

**Прямого терминала сервера в админке нет — это намеренно:** взлом админки дал бы полный контроль над сервером. Все серверные действия идут через SSH.

Полезное на сервере: `pm2 logs barakat` (логи), `pm2 restart barakat`, `npm run admin:unlock`, `npm run admin:reset-2fa`.
